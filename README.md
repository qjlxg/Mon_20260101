大摩：予老铺黄金“增持”评级 目标价降至505港元
格隆汇8月11日｜大摩发布研报称，将老铺黄金目标价由590港元下调至505港元，予“增持”评级，调整主因是基于较预期较弱的2026年第二季业绩，以及黄金价格环境下降，导致公司收入与盈利预测增量。大摩将老铺黄金2026年预测收入及盈利削减14%，以及2027-28年预测收入及盈利削减11-12%，以反映在较低金价环境下2026年第二季业绩弱于预期。
