摩根士丹利 称数据中心资产支持证券或需调整交易结构
摩根士丹利一份研报指出，投资者希望债券存续期内能够实现部分或全部去杠杆，数据中心资产支持证券（ABS）交易可能需要做出结构性调整。策略师 Carolyn Campbell、James Egan 以及 Vishwanath Tirupattur 在报告中写道，我们认为，投资者对 AI 整体叙事信心下滑，并不是数据中心 ABS 需求走弱的原因。在我们看来，数据中心证券化信贷市场显然正在趋于饱和，至少当前这类交易结构与资产特征已经到了这个阶段。短期来看，数据中心发行方大概率仍会在现有主信托框架内操作，推出贷款价值比更低、久期更短的交易，并以明显折价发行债券。利差可能继续走阔，但当前水平具备吸引力，短久期品种尤为突出。在固收市场各类标的里，数据中心 ABS 发行体量独立；即便相比其他 ABS 债券利差更高，也未必能自动吸引新增需求。对发行方而言，基准利率带来的压力或许更大。
