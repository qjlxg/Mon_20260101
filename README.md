【AI辅助设计禽流感疫苗动物实验获进展】金十数据11月8日讯，英国剑桥大学日前发布公报说，该校团队借助人工智能（AI）设计的一种新型广谱禽流感疫苗，在动物实验中对多种禽流感病毒变异株展现出防护效力。这款候选疫苗由剑桥大学与其衍生企业共同研发。研究人员收集全球监测项目记录的禽流感病毒基因序列数据，利用AI工具整合分析，设计出一系列包含这类病毒共同抗原特征的“超级抗原”。抗原是疫苗中能够触发机体免疫反应的成分。团队经细胞测试筛选后，将选定抗原用于疫苗并开展动物实验。实验显示，接种新疫苗的小鼠和雪貂在受到多种遗传特征不同的禽流感病毒变异株攻击后全部存活，而对照组接种现有禽流感疫苗的动物仅约半数存活。受试病毒变异株均曾引起人类感染，具有潜在大流行风险。研究负责人、剑桥大学教授乔纳森·希尼表示，新疫苗旨在针对多种禽流感病毒变异株提供广谱保护，应对病毒演化带来的挑战。利用AI工具可大幅加快疫苗设计流程。
