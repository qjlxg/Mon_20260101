大摩：上调MSCI欧洲指数2027年底目标至3030点
格隆汇11月17日｜摩根士丹利把MSCI欧洲指数2027年底目标上调至3030点，较现水平有约15%潜在升幅，并指欧洲股市面对的结构性利好因素可支持进一步上升。该行同时把欧洲相对美国的估值折让收窄至16%，预测2026至2028年盈利增长分别为21.9%、7.5%及4.5%，又认为银行股占比上升及回购收益率首次超越美国，是支撑欧洲股市的重要因素。

【快评：市场量能再度萎缩 短线情绪持续降温】
成交量方面，量能再度萎缩，第一个小时两市缩量738亿元，预计全天成交仅1.36万亿，或将刷新年内新低。当前下跌个股超3700家。板块方面，市场剧烈分化，题材弱势轮动。芯片产业链早盘异动拉升，综艺股份、西陇科学、国林科技、联合化学、有研新材涨停；华为算力概念表现活跃，华胜天成3天2板，真视通、嘉环科技涨停；另有电网设备、网络安全、家电等方向轮动。短线情绪持续降温，连板股晋级率跌至一成，跌停个股数量攀升，高位人气股集体走弱，百洋股份、永臻股份、闽发铝业走出3连跌停，文投控股、大晟文化跌停。

高盛 ：AI学习应用爆发，维持新东方及好未来“买入”评级
高盛发表研报指，根据教育行业10月份数据，八大主要学习设备品牌于主要电商平台合计GMV同比跌28%，对比9月为同比跌32%。其中好未来于主要电商平台售出约9.2万部，GMV约3.77亿元，GMV同比跌幅收窄至29%、环比升12%(9月为同比跌34%、环比跌5%)，平均售价同比升21%、环比跌5%。人工智能学习应用方面，豆包学习截至10月底日活跃用户同比升107%；传统学习形式则受压，线下非学科类培训牌照数目收缩，非学科类培训应用在线用户参与度整体偏弱，惟好未来旗下学而思培优除外。高盛认为学习平板及线下业务增长压力持续，但人工智能学习应用用户参与度继续上升；该行维持对新东方及好未来“买入”评级，并维持对东方甄选“沽售”评级；对新东方港股及美股目标价分别为54港元及69美元，好未来目标价16.1美元，东方甄选目标价17港元。

主力资金监控：长鑫科技净卖出超8亿
财联社11月17日电，财联社盯盘数据显示，今日早盘主力资金净流入家用电器、半导体、光学光电子等板块，净流出文化传媒、机械设备、通信等板块，其中文化传媒板块净流出超24亿元。个股方面，有研新材主力资金净买入超11亿元位居首位，华胜天成、寒武纪、阳光照明获主力资金净流入居前；长鑫科技遭净卖出超8亿元，中际旭创、吉视传媒、澜起科技资金净流出额居前。

午评：科创50指数半日涨超3% 芯片产业链集体反弹
财联社11月17日电，市场震荡回升，深成指、创业板指翻红，科创50指数涨超3%，此前一度跌超1%。沪深两市半日成交额8946亿，较上个交易日缩量59亿。全市场超3500只个股上涨。盘面上，芯片产业链早盘异动拉升，东方嘉盛、怡达股份、综艺股份、西陇科学、国林科技、联合化学、有研新材涨停；华为算力概念表现活跃，华胜天成3天2板，真视通、嘉环科技涨停；家电板块反复活跃，长虹美菱、小熊电器走出2连板，北鼎股份涨超15%。下跌方面，煤炭板块走弱，新大洲A、郑州煤电、云煤能源、昊华能源纷纷下挫；AI漫剧浙文影业、湖北广电、横店影视跌停。截至收盘，沪指跌0.01%，深成指涨0.69%，创业板指涨0.72%。
