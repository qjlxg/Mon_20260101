          信心和盲从是两回事，中国股民信息匮乏，盲目自信与真正对国家的经济走势有信心上两回事。我仍然坚持此前的判断：短痛胜过长痛。如果创业板能够快速打到377天线附近，完成一次充分的技术调整，那么反而有机会重新构筑一个更加扎实的底部；如果始终不愿意调整，只是在高位反复震荡，那么每一次反弹都可能成为新的套牢盘，最终形成更长时间的调整。
          接下来如果创业板快速向377天线靠拢，我反而会更加关注这里有没有出现真正的承接力量。跌得快不可怕，最怕的是阴跌；一次性释放风险不可怕，最怕的是拖成漫长的钝刀子行情。
