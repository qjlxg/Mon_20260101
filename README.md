【美国LNG出口创下新高，或有助于缓解市场压力】金十数据11月16日讯，随着多个项目产量增加，美国液化天然气（LNG）出口量创下新高。这一趋势或许能为全球市场提供喘息机会——此前，中东战事引发的供应短缺已令全球市场动荡不安。根据彭博数据，上周六，输往美国各液化天然气出口设施的管道天然气总量估计已攀升至约218亿立方英尺。这一数字不仅创下历史新高，还比一年前的水平高出12%以上。Golden Pass和Sabine Pass液化天然气设施的运营活动推动了供应量的增长。数据显示，上周六输往Golden Pass项目的管道天然气量创下历史纪录，而输往Sabine Pass的天然气量也达到了自4月以来的最高水平。

【三井日兴：利率前景转变，投资者重返日本国债市场】金十数据11月16日讯，三井日兴指出，随着日本国债收益率的飙升显现出见顶迹象，加之市场对人工智能（AI）相关问题的担忧加剧，国内外投资者正纷纷增持日本国债。三井日兴金融市场部负责人Keita Matsumoto在表示：“我们可能正处于一个重要的转折点。”他指出，尽管通胀风险和货币政策的不确定性仍在引发市场波动，但投资者显然正在调整仓位，为未来收益率可能出现的下行做准备——此前数月，他们一直押注利率会持续走高。过去一个月，日本国债价格走强。一方面，处于数十年高位的收益率吸引了基金经理入场；另一方面，受对人工智能相关担忧驱动的全球股市抛售潮，也推升了市场对避险资产的需求。截至11月6日的一周，外国投资者已连续六周净买入日本国债，创下自2020年3月以来的最长连续净买入纪录。
