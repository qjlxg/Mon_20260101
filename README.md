高盛 ：美国数据中心建设热潮有望持续至 2028 年，推高电力与天然气需求
高盛集团表示，受人工智能（AI）热潮推动，美国数据中心电力容量的强劲增长态势有望持续至2028年；随着数据中心在数量、规模及电力密度方面的不断提升，这将对电力和天然气需求构成上行风险。该行指出，到2028年，美国数据中心电力容量有望新增52吉瓦（GW）。 高盛在周二发布的一份报告中称：“今年以来，美国数据中心电力容量及需求增长了近30%，贡献了美国电力需求总增量的三分之一以上。”这种快速扩张可能会进一步加剧美国电力市场的供应紧张，并推高天然气需求；这进一步强化了高盛对2028年至2030年间亨利枢纽（Henry Hub）天然气价格的看涨预期。不过，高盛指出，美国中期选举后可能出现的政策调整，或许会减弱上行风险。该行在报告中补充道：“我们预计，数据中心增长的加速，不仅得益于设施数量的增加，还源于其物理占地面积的不断扩大以及功率密度的提升。”
