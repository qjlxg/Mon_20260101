1. 记者采访行业人士和环评机构获悉，目前推进的是采矿项目环评程序，配套的选矿厂和尾矿库因矿种变更同样需要走环评变更流程，目前尚无公开信息可查。上述人士表示，枧下窝锂矿要实现真正意义上的全面复产，选矿厂和尾矿库的环评变更流程仍是一道绕不开的“硬门槛”。

4. 此外，记者注意到，该项目配套尾矿库的安全生产许可证即将到期，或需申请延期。信用中国官网显示，奉新时代陶瓷土（含锂）矿综合利用项目尾矿库项目于2025年4月1日获批安全生产许可证，有效期至2027年1月14日。
