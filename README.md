摩根大通策略师Jay Barry团队表示，明年美国资金条件应保持“大体有序”，尤其是2027年上半年，因此3月SOFR与联邦基金利率基差定价有误。“强劲的需求和交易商的中介作用应能支持稳健的市场功能和流动性状况。”策略师预计，货币市场基金的资产管理规模在2027年将增加5000亿美元，即6%。他们还预计，美国证券交易委员会（SEC）关于国债回购清算的截止日期至少在短期内对回购水平的影响有限。他们认为3月SOFR\/联邦基金利率基差定价有误，并可能从目前的-3个基点水平扩大，特别是随着财政部一般账户（TGA）降至7000亿美元左右、准备金升至约3.2万亿美元以及短期国债偿还发生时。“宽松的资金背景”也支持了前端和中端互换利差扩大、长端保持“大体稳定”的观点，预计利差曲线将在年中前趋于平坦。由于收益率曲线最前端的风险调整后持有收益看起来最具价值，前端利差对于寻求持有收益的投资者来说也可能具有吸引力。

高盛 称市场仓位信号预示标普500指数回报将高于平均水平
高盛表示，其情绪与仓位指标已降至第36百分位，为“解放日”（Liberation Day）以来的最低水平，从历史数据来看，这一水平通常有利于未来的股票回报。策略师克里斯蒂安·穆勒-格利斯曼（Christian Mueller-Glissmann）指出，当仓位落入第30至40百分位区间时，标普500指数在多个时间跨度内的历史回报率均高于平均水平。上周，杠杆基金削减了约700亿美元的纳斯达克期货敞口，同时对冲基金降低了净杠杆率。与此同时，散户投资者继续逢低买入科技股，自9月下旬以来，杠杆型科技ETF的资金流向变动约为150亿美元。高盛认为，这种剧烈的仓位重置可能为市场复苏提供支撑性环境。

摩根大通 发布最新大宗商品展望
