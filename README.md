2026.9.23【收评：人要为自己的智商买单】
         今天的A股，终于把我昨天担心的问题进一步暴露出来了。昨天还是科技、AI应用热闹非凡，今天房地产、PCB、CRO、贵金属、复合铜箔等方向轮番表现，看起来到处都有机会，但指数却没有得到真正的推动。早盘三大指数高开低走，沪指、深成指和创业板指一度全部走弱，市场超过3500只个股下跌。
         我一直认为，市场真正需要的是一条能够持续吸引资金的领涨主线，而不是每天换一个板块出来表演。今天房地产冲高之后明显回落，传媒调整，海运、煤炭也走弱，资金又转向PCB、CRO、玻璃基板等细分方向。热点不是没有，而是太零散了，这种行情最大的特点就是看起来很热闹，实际上没有一个板块能够把市场真正带起来。
         这就是我反复说的“遍地开花”的问题。多点开花并不可怕，因为资金仍然有一个核心方向；真正危险的是遍地开花，所有板块都想表现，资金却没有办法集中。最后的结果往往就是热点之间互相争夺资金，指数缺乏持续推动力，个股却越来越难做。今天半日成交只有约1.16万亿元，而且比上一交易日同期缩量超过2600亿元，更说明资金追涨意愿正在下降。
        我的判断依然很明确：没有领涨主线，就没有真正持续的上涨行情；遍地开花越明显，后面的调整压力反而越大。 现在最应该做的不是追着热点跑，而是耐心等待市场真正形成一条能够持续领涨的主线。创业板377天线没有完成确认之前，我仍然坚持原来的思路，继续关注低估值、有业绩支撑的股票，等待市场真正把调整压力释放出来。
