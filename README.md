摩根大通策略师杰伊・巴里、哈里・唐尼、阿曼达・伯克在研报中称，美联储、银行以及货币基金明年对美债的需求下滑，有望被海外官方机构的稳健买盘对冲，买盘集中在短端。策略师预计负债驱动投资（LDI）资金与共同基金将带来趋势性需求。尽管美债 “需求缺口” 规模不小，但不会对期限溢价造成 “重大冲击”，原因是 2027 年一半的净发行为短期国库券。“更大的压力大概率在下半年显现，财政部届时将引导市场接受更高附息债券的发行规模。” 他们写道，“和 2023 年情形类似，在长久期供给落地前，这一变化就会推升期限溢价，令长端收益率维持相对高位。”策略师判断，至少 2027 年上半年，并不需要动用储备管理购债操作；2 月债务上限约束将至，财政部届时将结合特别举措、动用 TGA 账户资金，避免技术性违约。

花旗 预计美联储明年转向降息
花旗11月20日表示，美股估值持续下跌及AI投资放缓风险正在限制美联储进一步加息的空间。该行指出，美联储目前面临两难局面：高于2%目标的通胀要求其继续加息，而金融条件收紧及AI投资放缓风险则要求其降低利率，目前后者正逐渐占据上风。过去一年美国经济增长在很大程度上依赖AI相关投资，美联储主席沃什此前也表示美国经济并未过热，无意抑制经济增长。因此，花旗认为美联储官员不会愿意在股市遭遇抛售之际持续加息。考虑到美联储对抗通胀信誉的担忧，花旗仍预计12月将加息25个基点，但鉴于市场通胀预期已处于较低水平、能源价格有所回落，预计美联储将在12月加息后暂停行动，并于2027年晚些时候开始降息。
