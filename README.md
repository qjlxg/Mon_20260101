摩根大通 预计，人工智能相关发债热潮将推动2027年美国高评级债券供应创下纪录
摩根大通表示，大型科技公司在人工智能基础设施建设方面的支出，以及较高的再融资需求，将推动美国投资级债券发行量再创历史新高。以Nathaniel Rosenbaum为首的摩根大通策略师在周五的报告中写道，预计明年美国高评级债券供应量将达到2.1万亿美元，超过该行预计今年将创下的2万亿美元发行纪录。他们补充称，随着市场持续增长，每年2万亿美元及以上的发行量“可能日益成为常态”。该行表示，明年净新增发行量预计主要由科技和媒体公司的借款支撑，这两类公司合计将发行6120亿美元债券，占全部投资级债券供应量的近30%。这一总额包括所谓超大规模云服务商发行的2250亿美元，以及与数据中心和计算芯片融资交易相关的另外2250亿美元。 Rosenbaum 表示：“供应将异常集中于为人工智能基础设施建设项目提供融资的行业，这加大了我们总体预测对人工智能资本支出周期的敏感度。”该行预计，在经历了2026年的历史性高峰后，并购债券供应将同比骤降52%，但策略师表示，更强劲的“动物精神”仍是一项关键上行风险，可能推动交易撮合和整体发行量超出其预期。与此同时，中期选举中民主党获胜后，几个关键州的许可和开发问题可能推迟2028年的数据中心项目，并抑制科技企业借贷。如果超大规模云服务商继续将更多债券发行转向外币而非美元，供应也可能受到冲击。
