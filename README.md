中国公安部公布15起涉灾谣言案 当中涉利用AI生成
中国近期多地遭遇台风、暴雨和洪涝，网络上也出现移花接木、利用人工智能（AI）生成虚假灾情等涉灾谣言。中国公安部星期一（8月10日）公布15起典型案例，多名涉事网民已被行政处罚。
据央视新闻客户端消息，中国公安机关网安部门依托“净网—2026”专项行动，持续严厉打击编造传播涉汛等涉灾网络谣言违法犯罪活动。此次公布的15起案例涉及广东、安徽、甘肃和广西等地，其中多起发生在广东。
造谣方式包括剪辑拼接其他地区的灾害画面、使用往年灾情视频，以及利用AI工具生成或篡改虚假信息。
其中，广东深圳一名36岁陈姓网民剪辑拼接美国飓风肆虐致城市严重损毁的现场画面，在抖音平台发布并谎称系台风“红霞”灾情现场。目前，他已被属地公安机关行政处罚。
另一名37岁深圳陈姓网民则利用AI工具篡改当地发布的《台风天配送安全通知》，再将相关截图散布至微信；广东清远一名36岁杨姓男子也使用AI生成多篇有关停课、停业和停工的虚假通知。两人均已被行政处罚。
此前，中国国家网信办微信公号7月23日发文称，中共中央网信办和应急管理部联合印发通知，在全国范围内部署开展“汛期灾害事故违法不良信息”的集中清理整治。
行动将重点整治五类问题，包括移花接木与恶意剪辑、旧闻翻炒与历史嫁接、夸大其词与虚构数据、编造险情与冒充权威、技术伪造与借机诈骗等。
通知要求，各地网信部门要聚焦灾害事故违法不良信息的典型问题及隐形变异问题，开展全面排查，督导网站平台压实主体责任，健全内容审核及账号管理机制。
每年7月下半月至8月上半月是中国主汛期的重要阶段，有“七下八上”之称，降雨集中、洪涝灾害多发。受台风、持续强降雨影响，中国多地近期出现洪涝、龙卷风、山体滑坡等严重险情灾情。
