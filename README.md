         为什么我反复强调610天线？这是我独创的10条黄金均线中最长期的一条，我们称为牛熊分界线，研究中国股市历史可以发现，所有指数有效突破610天线后都会产生一波大行情，而一轮牛市行情结束也必然以击破610天线为标志，有效击破610经常意味着将会发生漫长的调整！
         我一直强调，科技产业有真正的成长机会，但这不代表所有贴上科技标签的股票都值得投资。真正有技术壁垒、有商业模式、有持续盈利能力的科技企业，与单纯依靠概念、故事和资金推动股价的公司，根本不是一回事。
        前期一些科技概念被反复炒作，股价不断上涨，很多参与者只看到涨幅，却不愿意认真审视估值、业绩和实际商业价值。只要股价上涨，故事就被当成了未来；一旦资金退潮，原本被忽略的问题就会集中暴露。估值脱离基本面越远，股价就越容易受到情绪逆转的冲击。恶炒科技概念，是一条高风险的路，最终往往要付出沉重代价。
        被套之后，真正应该反思的不是自己为什么没有及时卖在最高点，而是当初为什么买入。如果买入的理由只是某个热门概念、某条市场传闻，或者看见别人赚钱就忍不住跟进，那么即使这一次侥幸获利，下一次也可能再次付出代价。市场最残酷的地方，在于同样的错误可以不断重复，而每一轮行情都会让人误以为这一次有所不同。
        我的核心观点很明确：450天线已经失守，610天线的重要性正在上升；接下来创业板必然会考验610牛熊分界线，低估值的股票才能扛住这种系统性下跌，至少跌幅会远小于概念性股票，而概念性股票按照中国股市的历史，一轮牛熊转换的跌幅常达到90%，就你们买的这些垃圾股，斩腰我都不会看，科技故事会有如庞氏骗局，最后你们会发现绝大部分股票一文不值！

摩根大通最新研报指出，CoreWeave需将活跃数据中心电力的年新增规模提升至4至5倍，方能实现正向自由现金流的拐点。该行预计这一拐点将在2030年出现，届时活跃与新增产能比率将达到4.5倍。公司目前的现金赤字源于产能扩张的绝对速度，而非单体设施的经济效益不佳。具体而言，每吉瓦（GW）新增产能需约350亿美元的前期资本开支，而稳定运营后年营收为100亿至150亿美元，年现金EBITDA约为94亿美元（利润率75%）。由于CoreWeave在2026年初拥有0.85GW活跃电力，年内新增1.0GW，其活跃与新增产能比率仅为0.9倍。公司无法在将规模从2026年底的1.85GW扩张至2030年8GW（扩大四倍）的过程中实现自我融资。摩根大通预测，年新增产能将在2027年加速至1.5GW（比率1.2倍），2028年增至1.6GW（比率2.1倍），2029年增至1.6GW（比率3.1倍），并在2030年新增1.5GW时达到4.5倍。随着稳定运营的吉瓦数不断累积，成熟产能产生的现金EBITDA将迅速扩张，足以吸收新设施所需的每吉瓦350亿美元资本开支。
