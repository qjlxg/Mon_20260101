【欧盟与印尼签署贸易协定 将取消大部分商品关税】金十数据11月23日讯，欧盟与印度尼西亚签署协议，将取消双方大部分商品贸易关税。经过逾10年的谈判，欧盟于上周六在布鲁塞尔宣布与印尼达成全面经济伙伴关系协定。双方还签署了投资保护协定，以促进双向投资流动。欧盟主要出口产品（包括肉类和乳制品）的关税将被取消，而汽车、机械、化工产品和药品的现有关税将被下调。据印尼经济事务统筹部介绍，印尼出口至欧盟的商品中约90%的关税将被取消，其余关税将在3至15年内逐步降低，或适用关税配额优惠。协议实施后，预计未来15年欧盟对印尼的出口将增长近40%，而印尼对欧盟的商品和服务出口预计将增长逾14%。欧盟委员会预计，相关协议将使欧盟GDP增加160亿欧元，印尼GDP增加270亿欧元。双方达成的投资及经济伙伴关系协定仍需获得欧洲议会批准，并完成印尼国内批准程序。预计协议将于2027年初开始临时适用。

2026.11.23【午评：别吵吵，这利好无卵用】
         上周五美股暴跌，周末A股管理层又放出所谓利好消息。消息一出，市场上立刻热闹起来，仿佛一剂猛药就能扭转行情。别吵吵，这种利好我早就不看好。今天早上我就在蓝天网站直播中明确表达了这个观点：历史上类似的利好出现过多少次？哪一次真正阻止了市场下跌？它最多只能在短期内对冲一下美股暴跌带来的利空，根本改变不了A股自身的运行趋势。
         我当时判断，今天A股大概率高开低走。实际走势虽然没有高开，却是探底回升之后迅速回落，整体运行方向与我的判断差距不大。早盘创业板指和深成指一度双双翻红，看起来似乎有些起色，但全市场超过3700只个股下跌，说明这场反弹并没有得到多数股票的响应。沪深两市半日成交额9164亿元，较上个交易日放量606亿元，成交量增加了，赚钱效应却没有跟上，这样的反弹有什么值得欢呼的？
          盘面热点倒是不少。人形机器人概念走强，安培龙20CM涨停，克来机电、长华集团两连板；AI漫剧方向的浙文影业、横店影视、上海电影等涨停；PCB板块中京电子三连板，崇达技术、世运电路涨停；CPO方向青山纸业涨停，新易盛、天孚通信涨幅超过8%。但我想提醒大家，热点多不等于行情好，几个板块轮番表现，也不代表市场已经形成了真正的主线。超过3700只股票下跌，这才是早盘市场最真实的底色。
         房地产板块震荡调整，金科股份、三湘印象、大悦城等纷纷回落。更值得注意的是科创板，今天下跌2.65%，明显弱于其他主要指数。这与我此前对科创板补跌风险的判断一致。科创板前期积累的估值泡沫并没有因为周末一则利好就消失，真正的调整压力也不会因为几只权重股短暂拉升而凭空消失。该补的跌，终究还是要补。
         截至午间，沪指下跌0.96%，深成指上涨0.24%，创业板指上涨1.22%，科创板下跌2.65%。几个指数涨跌不一，个股却普遍承压，这种指数分化恰恰说明市场缺乏统一的做多力量。周末的利好没有让市场出现预想中的强势反攻，反而再次暴露出一个问题：A股现在究竟靠什么才能真正走强？靠消息刺激，靠少数权重股，还是靠几个热点题材轮番表演？这些都不是能够持续推动市场上涨的答案。
