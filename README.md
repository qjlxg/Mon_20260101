大周先生：
【收盘前分析】
今天大盘窄幅震荡，上证指数在日线上是一个极小线，通常大阳之后出现震荡是很正常的走势，虽然创业板指和深成指的日线是实体阴线，但只要上证指数保持技术结构，目前暂时不用过度在意它们的短线波动。
上证指数是比较强势，外围市场出现了大跌，日韩指数跌幅较大，重要是今天上证指数是没有在护盘的情况下有着强势的表现，说明A股是不能看空的，所以目前对于今天这根十字星，我更倾向于把它理解成大阳线之后的中继整理，而不是转弱信号，A股暂时没有看空的必要。
盘面上农业和消费个股出现轮动，农业股这个和近期的一则消息有关，是高盛关于“厄尔尼诺后遗症”文章，分析明年农作物会暴涨，但这个逻辑距离真正兑现还有较长时间，所以现阶段更多还是短线资金围绕消息做轮动，并没有形成持续性的主线特征。
而消费板块多是小盘子个股，而代表大资金的白酒是没有动作的，
所以对于这类间歇性轮动板块，我们目前依然不做重点跟踪。
原因很简单，这些方向目前资金介入程度不高，主力仓位也不重，本身又缺乏指数带动作用。一旦市场重新出现调整，这类短线轮动方向往往也是最容易出现快速回落的。
主力资金虽然科技股出现了震荡，但都没有破坏趋势和结构，也因此维持对半导体，创新药和PCB的跟踪，不做调整。
整体观点保持不变：
1、指数维持震荡上行的判断，今天的极小线更多看作上涨过程中的中继整理。
2、机构资金的核心方向目前没有明显变化，继续围绕半导体（设备和材料）、创新药以及PCB等方向跟踪。
市场每天都会有新的板块冒出来，但真正值得我们花精力的，从来不是“今天谁涨了”，而是谁的资金在持续介入，谁的结构能够走出延续性。
