2026.9.18【收评：新的行情开始了吗？】
       昨天冲高回落，今天马上重新拉起来，而且比昨天更加热闹。创业板一度涨幅超过2%，科创50更是接近4%，半导体、存储芯片、光刻胶、算力硬件集体上涨，市场一度超过4500只股票上涨。看起来很强，实际上我看到的还是两个字：重蹈覆辙。
         我们前面已经说得很清楚，遍地开花必然带来调整。市场刚刚经历一次冲高回落，资金没有重新集中到真正安全的低估值方向，反而又开始到处寻找热点。今天半导体涨、消费涨、机器人涨、次新股也涨，资金再次撒胡椒面，这种行情短期可以很热闹，却很难真正走远。
          尤其是科技概念，我的观点没有改变。半导体今天确实强，部分个股甚至出现涨停潮，但问题还是那个问题：科技股里面真正让我们敢于长期持有的低估值股票并不多。如果资金继续靠概念、题材和高估值推动行情，那么涨得越疯狂，后面的压力反而越大。今天的上涨，并没有改变这个基本事实。
         创业板同样如此。今天涨得很猛，并不意味着上方压力消失了。恰恰相反，指数越往上走，前期套牢盘和短线获利盘越容易出来。创业板上方压力依然很大，377天线还没有真正到位，这一轮调整就不能轻易宣布结束。
         我并不反对反弹，但我反对这种没有经过充分调整、又重新“遍地开花”的反弹。真正健康的行情应该是资金越来越集中，估值越来越合理，最后形成一条能够持续的主线。现在恰恰相反，机构还是在老生常谈地炒作热门概念，哪里热就往哪里冲，至于估值是不是高、公司是不是值得长期持有，似乎已经被抛到脑后。
         我的判断依然简单：创业板377天线没有到，调整就没有真正结束；市场重新陷入遍地开花，反弹就很难持久。与其追逐今天突然冒出来的热点，不如继续守住前面已经看好的低估值股票，耐心等待市场重新寻找真正有价值的方向。

机构报告：企业应尽快设立或完善2030年前100%可再生能源消费与运营范围碳中和目标
近日，国际环保机构绿色和平、清华四川能源互联网研究院发布《绿色云端2026》报告。报告指出，过去几年，节能降碳技术已经在数据中心行业内得到广泛应用；但是，对于互联网科技企业而言，仅依靠节能技术无法最终实现零碳目标，即使PUE（电源使用效率）降至极致，也难以结构性减少能源供应所产生的碳排放，企业能否持续扩大绿电消费规模和占比，将越来越成为决定其碳中和进程的核心变量。报告建议，企业可从以下方面着手布局：一是应尽快设立或完善2030年前100%可再生能源消费与运营范围碳中和目标；二是扩大企业绿电消费规模与消费比例；三是在此基础上，进一步提出2030年前覆盖全价值链的碳中和目标，推动供应商以提升能效，消费绿电等方式降低碳排放。

摩根士丹利 ：华为昇腾960 SuperPoD采用NPO光互连 维持大中华科技硬件行业“与大市同步”
摩根士丹利发布研报称，华为昨日(17日)在上海华为全联接大会2026上公布昇腾960 SuperPoD人工智能基础设施，采用近封装光学(NPO)的第三代光互连架构。该行认为，华为采用NPO技术，支持其“中国有望在此新产品建立竞争优势”的观点;由Atlas 910C的分立光学，到Atlas 950的LPO，再到Atlas 960的NPO，突显华为光互连技术快速演进。该行指出，7.2 Tbps的NPO光引擎以36个通道、每通道200 Gbps运行，超越OIF等组织正在开发的6.4 Tbps、32通道接口，同时将通信延迟降至10纳秒，并降低功耗。昇腾960 SuperPoD可通过UnifiedBus扩展至4,096张NPU卡，提供高达8 Exaflops的FP8算力及1 PB统一HBM。该行表示，华为亦联同中国移动研究院、京东云及逾20家国内合作伙伴，推出“OPEN NPO”倡议及光互连多源协议(MSA)。该行对大中华科技硬件行业观点为“与大市同步”(In-Line)。
