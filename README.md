【我国首次载人登月任务乘组计划由三人组成，两人着陆月球表面】金十数据10月31日讯，10月31日，第七届载人航天学术大会在北京航空航天大学举行。我国计划在2030年前实现中国人登陆月球。计划采用了“两次发射，一次登月”的方式实现载人登月。中国载人航天工程副总设计师兼月球探测工程总设计师王翔在本届大会上介绍称，我国首次载人月球探测计划采用环月轨道对接飞行模式。据了解，这种模式将采用两枚长征十号运载火箭，先将着陆器送往月球轨道，然后再发射载人飞船与着陆器实现交会对接，航天员进入着陆器并与载人飞船分离着陆月面，开展有关科学探测活动。完成任务后航天员乘坐着陆器从月面上升，在月球轨道上与载人飞船实现二次交会对接，航天员乘坐载人飞船返回地球。王翔介绍称，我国首次载人月球探测任务乘组计划由三人组成，其中两人着陆月球表面。
