         我的思路依然很明确：不盲目追涨已经爆炒的题材，重点寻找低位、有业绩、有产业逻辑的第二梯队。今天上午的市场已经说明，A股并没有失去机会，只是机会正在从“单一主线”转向更加复杂的板块轮动。午后重点观察创业板强弱、科技股持续性以及医药和资源板块的承接力度。
