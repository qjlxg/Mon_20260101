花旗集团表示，日本在捍卫日元时不必抛售逾1.1万亿美元的美国公债持仓，即使其可动用的短期债券持有部位已所剩不多，仍有其他工具可供运用。以Jason Williams为首的花旗策略师在报告中写道，日本当局可以动用美联储的“海外和国际货币管理当局回购交易安排”（FIMA Repo Facility）。该机制允许海外央行以持有的美国公债作为抵押，向美联储取得美元流动性，无须出售公债筹措现金。
