         因此，后面的行情我反而希望看到适当收敛。如果科技股中真正有业绩、有产业趋势的方向继续保持强势，同时医药、贵金属、小金属等此前已经得到市场验证的方向继续轮动，这叫健康的多点开花；如果明天又换一批完全不同的题材集体上涨，后天再换一批，那么就要高度警惕“电风扇式行情”最终演变成普遍冲高回落。
