摩根大通 ：美国数据中心建设或放缓 风险料从2028年起显现
美国中期选举带来的政治格局变化，可能对人工智能（AI）数据中心建设及电力行业产生深远影响。但摩根大通认为，相关政策风险短期内不会显著改变AI资本开支计划，真正的影响可能从2028年开始显现。摩根大通11月4日发布研报指出，民主党不仅赢得国会参众两院控制权，还在得克萨斯州、佐治亚州、新墨西哥州和内华达州等重要数据中心市场赢得州长选举。随着多名州长当选人提出限制数据中心开发的政策，未来相关项目可能面临更严格的审批、更长的建设周期、更高的开发成本及更大的融资难度。该行预计，2027年数据中心资本开支计划不会出现重大变化，因为相关项目大多已经开工，而且多数已获得融资。相比之下，尚未获批或完成融资的2028年及以后项目将面临更大不确定性。
